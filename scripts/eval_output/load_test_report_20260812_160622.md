## 口径说明

- **缓存命中路径**：预热后对同一批问题重复请求，全部命中语义缓存（不调用 DeepSeek）；仍包含 query 向量化 + 会话/消息落库，代表接口真实吞吐。
- **冷路径**：全新问题，走混合检索 + Self-RAG（草稿+自省两段生成）+ DeepSeek，吞吐受 LLM 延迟与并发上限约束，代表首次提问的真实能力。
- 生产环境默认开启 20 次/分/用户的业务限流（防配额滥用），此处关闭限流测量的是系统容量上限。
